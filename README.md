## 🚀 ¿Qué es Komo?

Komo es una plataforma educativa digital que conecta estudiantes para compartir apuntes, acceder a tutorías personalizadas y completar cursos, utilizando una economía digital propia basada en **EightTokens (8T)**.

Cada logro, certificado y transacción queda registrado en **blockchain**, garantizando transparencia y verificabilidad permanente.

---

## ✨ Funcionalidades MVP

### 🏠 Landing Page
- Hero animado con fondo generativo
- Contador en tiempo real de estudiantes, tutores y tokens
- Sección de características con 6 pilares
- "Cómo funciona" en 3 pasos
- Cursos destacados con precios en 8T
- Sistema de tokenomics explicado

### 📊 Dashboard
- Bienvenida personalizada con nivel y racha
- Wallet de EightTokens con balance animado
- KPIs: cursos completados, apuntes subidos, tutorías, logros
- Feed de actividad **en tiempo real** con hashes de blockchain
- Compra de cursos directamente desde el dashboard
- Conexión de wallet MetaMask (simulada)
- Ganancia de tokens (demo interactivo)

### 🛍️ Marketplace (Explore)
- 6 cursos en múltiples materias
- 3 tutores con verificación blockchain
- Filtros por categoría (8 categorías)
- Búsqueda en tiempo real
- Ordenamiento por popularidad, precio, rating
- Flujo de compra con animación de éxito
- Tarjetas de tutor con badge "✓ Blockchain"

### 👤 Perfil
- Banner con badges ODS (4, 9, 10)
- Wallet con historial visual de tokens
- Gráfico de actividad mensual (ganado vs gastado)
- **6 Achievements NFT** con rareza: Común → Legendario
- Subida de apuntes con recompensa en tokens
- Progreso hacia Certificado Blockchain
- Historial de cursos comprados

## 🪙 EightTokens — La Economía del Conocimiento

| Acción | Recompensa |
|--------|-----------|
| Subir apuntes | +10 a +50 8T |
| Dar una tutoría | +15 8T/hora |
| Completar un curso | +25 8T |
| Racha de estudio | +5 8T/día |
| Primer logro | +10 8T |
| Conectar wallet | +30 8T |

## 🔗 Integración Blockchain

- **EightTokens**: Token ERC-20 nativo de la plataforma
- **Certificados NFT**: Logros verificables e inmutables
- **Reputación on-chain**: Score de tutores registrado en blockchain
- **Wallet connect**: Integración con MetaMask

## 🚀 Instalación y Desarrollo

```bash
# Clonar el repositorio
git clone https://github.com/Asss678/Komo.git
cd Komo

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build
```
